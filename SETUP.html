Setup ConvertAR

Guía paso a paso para dejar el backend funcionando en Pintos Home

Paso a paso — Setup completo
1
Crear cuenta en Supabase Gratis
Supabase es la base de datos donde se van a guardar los eventos de tracking y la configuración de cada tienda.
  • Entrá a supabase.com → "Start your project" → Registrate con Google o email
  • Hacé click en "New project" → Nombre: convertar → Región: South America → Generá una contraseña fuerte (guardala)
  • Una vez creado, andá a Settings → API
  • Copiá los 3 valores que necesitás:
    # Guardar estos valores SUPABASE_URL = https://XXXX.supabase.co SUPABASE_ANON_KEY = eyJhbG... (la "anon public key") SUPABASE_SERVICE_KEY = eyJhbG... (la "service_role key")
  • Andá a SQL Editor → copiá y pegá todo el contenido del archivo schema.sql → click "Run" → debe decir "Success"
2
Crear cuenta en Railway Gratis
Railway es donde corre el servidor Node.js. El free tier alcanza para empezar tranquilo.
  • Entrá a railway.app → "Login" → Entrá con tu cuenta de GitHub (si no tenés, creá una en github.com — es gratis y tarda 2 min)
  • Click en "New Project" → "Deploy from GitHub repo"
  • Si es la primera vez, autorizá a Railway a acceder a tus repos de GitHub
  • Subí la carpeta convertar-app a un repositorio de GitHub (nuevo, público o privado) — arrastrá los archivos desde el Finder
  • Seleccioná ese repositorio en Railway → click "Deploy Now"
  • Esperá ~2 minutos a que haga el deploy (vas a ver logs en tiempo real)
3
Configurar las variables de entorno en Railway
Las variables son como un archivo .env pero guardado de forma segura en Railway — nunca van al código.
  • En Railway, click en tu proyecto → click en el servicio → tab "Variables"
  • Agregá estas variables una por una con "Add Variable":
    SUPABASE_URL = https://XXXX.supabase.co SUPABASE_SERVICE_KEY = eyJhbG... (service_role) ADMIN_SECRET = una-clave-secreta-que-inventes PORT = 3000
  • Railway hace redeploy automático al guardar — esperá 1 minuto
  • Copiá la URL pública del servidor → en Railway, tab "Settings" → "Domains" → va a ser algo como convertar-app-production.up.railway.app
4
Verificar que el servidor está andando
Antes de conectar la tienda, confirmamos que el backend responde bien.
  • Abrí en el navegador: https://TU-APP.railway.app/
    Debe responder:
    { "ok": true, "app": "ConvertAR", "version": "1.0.0" }
  • Probá la config de Pintos: https://TU-APP.railway.app/config/pintoshogar
    Debe devolver el JSON de configuración
  • Si todo responde → el backend está listo ✅
5
Actualizar el snippet y pegarlo en Tienda Nube
Ahora conectamos la tienda de Pintos al backend.
  • Abrí el archivo snippet.js
  • Cambiá la línea API_URL:
    var API_URL = 'https://TU-APP.railway.app'; // ← tu URL real
  • Copiá todo el contenido del archivo snippet.js
  • En Tienda Nube: Configuración → Códigos externos → Para la tienda
  • Reemplazá el código actual con el nuevo snippet completo → Guardar
  • Abrí un producto de Pintos en el browser → abrí DevTools (F12) → Console
    No debe haber errores en rojo relacionados con ConvertAR
  • Verificá en Supabase → Table Editor → events → que empiecen a aparecer filas con event_type: "productView"
6
Abrir el panel de configuración
Ya podés gestionar todos los features desde el panel sin tocar más código.
  • Abrí el archivo panel.html en Chrome
  • Cambiá en el código: var API_URL = 'https://TU-APP.railway.app' y var ADMIN_SECRET = 'tu-clave'
  • Activá o desactivá features, configurá el FAQ, tags, countdown → click "Guardar cambios"
  • Los cambios se aplican en Pintos Home en tiempo real (el snippet lee la config cada vez que alguien visita la tienda)
  • En la sección "Analytics" vas a ver los datos de conversión en tiempo real
