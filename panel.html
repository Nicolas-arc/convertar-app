📋 Setup GTM
Un solo tag en GTM reemplaza todos los CVA individuales. Desde el panel controlás qué features están activas — sin tocar GTM nunca más.
⚡ Tag único (reemplaza todos los CVA)
Creá un nuevo tag en GTM → HTML personalizado → All Pages:
Pasos:
1. GTM → Nueva etiqueta → HTML personalizado
2. Nombre: CVA - Loader
3. Pegar el código · Activador: All Pages
4. Enviar versión
5. Pausar / eliminar los 7 tags CVA individuales anteriores
